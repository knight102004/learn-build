<br>
git config --global user.name "My Name"
→ Sets the name that Git uses for your commits.

<br>

git config --global user.email "email@gmail.com"
→ Sets the email associated with your Git/GitHub account and used for your commits.

<br>

git config --global --list
→ Displays the global Git configuration, including the name and email you just entered.
